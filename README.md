# 🌴 Tropical Python Engine (TroPy)

**TroPy** — это библиотека на Python для перевода абстрактной тропической математики (алгебры полуколец Max-Plus и Min-Plus) в прикладной код для оптимизации логистики, биоинформатики и машинного обучения.

> **Цель проекта:** Оцифровать фундаментальные академические статьи по тропической геометрии и предоставить бизнесу быстрые алгоритмы, работающие без тяжелых вычислительных умножений.

---

## 🚀 Основные возможности (Core Features)

*   **Универсальное Ядро (Tropical Core):** Поддержка вычислений в полукольцах `Max-Plus` и `Min-Plus`.
*   **Оптимизатор Расписаний (Scheduling Optimizer):** Прямой аналитический расчет временных графиков процессов и логистических цепочек.
*   **Валидатор Графов:** Автоматический поиск логических парадоксов и конфликтов в графах ограничений.
*   **Критический Путь (Critical Path Analyzer):** Визуализация и подсветка узлов с нулевым резервом времени через `NetworkX`.
*   **Генетический Модуль (Bioinformatics Core):** Расчет тропических метрик близости ДНК-последовательностей для эволюционных деревьев.

## 🛠️ Быстрый старт (Installation & Usage)

1. Клонируйте репозиторий и установите зависимости:
```bash
git clone https://github.com
cd tropical-python
pip install -r requirements.txt
```

2. Запустите комплексный тест логистической оптимизации:
```bash
python examples/run_scheduling.py
```
